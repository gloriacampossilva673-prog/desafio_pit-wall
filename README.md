# PITWALL – GP São Paulo 🏎️

## Contexto

O PITWALL é um projeto de desenvolvimento web inspirado no Grande Prêmio de São Paulo de Fórmula 1. A proposta é criar um site com informações sobre a corrida, os pilotos e os ingressos, utilizando um visual moderno inspirado no universo automobilístico.

## Objetivo

O objetivo deste projeto é colocar em prática os conhecimentos adquiridos nas aulas de HTML e CSS, desenvolvendo uma página organizada, visualmente atrativa e fácil de navegar.

## Sobre o Projeto

O site apresenta diferentes informações sobre o GP de São Paulo, como:

- **Página inicial:** apresentação do Grande Prêmio de São Paulo.
- **Informações da corrida:** número de voltas, distância e quantidade de curvas.
- **Pilotos:** cards com informações dos pilotos participantes.
- **Classificação:** área com a posição dos pilotos.
- **Ingressos:** informações sobre os valores dos ingressos.
- **Formulário:** espaço para preenchimento de informações.

## Tecnologias Utilizadas

- HTML5
- CSS3

## Desenvolvimento

O projeto foi desenvolvido utilizando HTML para estruturar o conteúdo da página e CSS para trabalhar a aparência, as cores, o posicionamento dos elementos e a organização das informações.

O design utiliza principalmente as cores preto, vermelho e branco, trazendo uma identidade visual inspirada nas corridas de Fórmula 1.

## Conclusão

Com este projeto, foi possível praticar os conceitos de HTML e CSS aprendidos em aula, desenvolvendo uma página que reúne informações sobre o GP de São Paulo em um único lugar.
